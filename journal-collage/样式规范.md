## 字体
- 正文：思源宋体 / Noto Serif CJK SC，17px，行高 1.5
- 标签、时间戳、设置副标题：思源黑体 / Noto Sans CJK SC
- 设置项标题 17px 加粗 字距 .1em；副标题 13px；分组吊牌 15px 字距 .2em

## 描边与阴影
- 卡片 / 按钮 / 标签描边：2px #1F2A3A
- 硬阴影：偏移 (4,4) 纯色 #1F2A3A（卡片）、(2,2)（按钮、标签、吊牌）
- 软阴影：0 10px 20px rgba(40,25,5,.18)
- 气泡：drop-shadow 0 3px 0 rgba(31,42,58,.18) + 0 8px 14px rgba(60,40,10,.15)

## 旋转角度
- AI 活页纸 -0.6°；用户牛皮纸 +0.8°
- AI 拍立得 -6°；用户拍立得 +5°
- 「思考过程」标签 -2°；日期块 -2°；分组吊牌 -2°
- 设置卡片交替 +0.4° / -0.5°
- 胶带 -8° ~ +4°；贴纸 +8°；印章 -14°

## 尺寸
- 拍立得头像 50×58，内图 42×38，上白边 4，下白边 10
- 胶带 84×22；拍立得上的小胶带 38×12
- 贴纸 64~76px 见方；印章 64（标题栏 52）
- 气泡最大宽 300，内边距 14 18 16
- 输入区：牛皮纸口袋，内缩 7px 虚线框（1.5px dashed rgba(31,42,58,.5)）
- 圆形按钮 46；发送按钮红底白箭头；模型选择框高 40，-1°
- 设置图标方块 44×44，描边 2px，硬阴影 (2,2)，交替 -4° / +3° / -3°，底色 蓝 / 粉 / 黄 轮换
- 分组吊牌：左侧切角 12px，带 7px 打孔圆点；底色 黄 / 蓝 / 粉 / 绿 轮换
- 设置项分隔线：2px 虚线 #1F2A3A，透明度 .35，节距 6/5
